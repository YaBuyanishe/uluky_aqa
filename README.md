### Описание
Проект содержит автоматизированные тесты для проверки функциональности веб-приложения AB Payments.  
Тесты написаны с использованием **Playwright** и **TypeScript**.

### Установка и настройка
1. **Клонировать репозиторий**
   ```bash
   git clone <url-репозитория>
   cd <папка-проекта>
2. **Установить зависимости**
   ```npm install```
3. **Настроить переменные окружения**
    Создайте файл .env в папке e2e/
    Ключи переменных можно найти в файле /e2e/env.d.ts
    Значение переменных можно получить на тестируемой платформе

### Запуск тестов
Находясь в папке проекта выполнить
```
cd e2e
npx playwright test
